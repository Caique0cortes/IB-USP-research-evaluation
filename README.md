**Build a scientific collaboration network**

• Quantify collaboration between researchers

• Compare publication productivity before and after joining the institute

• Compare scientific productivity between men and women

• Measure publication frequency

• Evaluate publication during undergraduate and master's studies

• Produce interactive network visualizations
